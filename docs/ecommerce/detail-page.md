# 详情页与A+模块规划

从买家问题安排阅读顺序：识别商品→适用场景→关键卖点→细节与规格→使用与边界→发货和信任信息。每一屏解决一个问题，避免重复大标题堆长页。

## 先做模块简报

| 模块 | 输入 | 交付 |
| --- | --- | --- |
| 开头 | 商品、核心使用任务 | 主体＋一句准确价值说明 |
| 场景 | 获准场景、真实尺寸 | 背景与真实主体合成 |
| 细节 | 局部实拍、材质事实 | 特写＋有来源的标注 |
| 规格 | 已确认参数与配件表 | 可读表格／示意图 |
| 使用 | 实际操作步骤 | 顺序图与准确提示 |

先输出逐屏文案和图片清单，核对后逐屏制作。长页拼接前检查裁切、字号、边缘和模块重复。A+按当前站点、账户和所选模块的实际输入限制规划，不把旧模板宽度当通用规定。

提交时提供整页预览、分模块图片、准确文字与源文件状态。未创建PSD、无法编辑或未实际导入的平台内容要分别说明。跨境本地化见[跨境交付](/ecommerce/cross-border)。
