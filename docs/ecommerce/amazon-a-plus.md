# Amazon A+：把图片改成模块化说明

A+先选择当前账户可用的模块，再安排图和文字。把国内长详情页缩成一张图片，会让文字、模块和手机阅读一起失控。用DN01练习时，品牌故事只写真实提供的内容，虚构练习名不补创始人经历。

## 第1步：记录实际模块

打开当前A+编辑器，登记模块名称、图像槽位、推荐／要求像素、文字字段与手机预览。不将某个常见宽度写成所有Basic或Premium模块的统一尺寸。账户可用模块未提供时，可以先完成模块内容方案，导出像素列待填。

Amazon公开设计指南建议图文合理搭配、遵守模块尺寸，并强调手机阅读时的文字处理。[官方A+设计指南](https://sell.amazon.com/blog/a-plus-content-design-guide)。本教程只采用任务组织方法，不把文章中的示例当作你的账户能力。

## 第2步：给每个模块一个问题

| 内容单元 | 买家问题 | 练习内容与输入 |
| --- | --- | --- |
| 开头 | 这是什么、在哪里用 | DN01实拍与书桌场景 |
| 结构 | 怎么安排文具 | 开盖、可拆隔板实拍 |
| 规格 | 是否能放到桌面 | 220×150×120 mm外尺寸记录 |
| 使用 | 怎么打开和摆放 | 经核实的操作步骤 |
| 配件 | 实际收到什么 | 盒体1、盖子1、隔板1 |

这是五个内容单元，不要求必须使用五个模块。根据实际模块合并或拆开；不为了填满模块捏造其他型号、测评或性能。

## 第3步：逐模块制作

复制[P12 A+规划](/prompts/P12)，得到各模块的图片简报、准确文案和缺失项。先做一张场景底图，再做结构与尺寸。把文字放在支持的原生字段或独立排版层；长说明优先用文本模块。

对比图只比较真实存在、已提供参数的型号。当前练习只给DN01时，不编造竞品和第二型号。热点、轮播、视频等只有实际模块支持才纳入交付。

## 第4步：检查与返工

逐模块检查图像裁切、字体、单位、发货内容和事实依据，再看桌面与手机预览。文字错误只改文字字段／图层；结构错误回到对应实拍与合成步骤；尺寸不合适重新排版该模块。

交付保留模块清单、独立图片、准确文字、源文件和预览状态。没有进入账户编辑器时，只报告“模块内容方案已完成”，不报告“已上线”或“已通过审核”。
