# Amazon主图与副图：一步一步制作

本教程以DN01普通收纳盒为练习，面向Amazon US商品页。先核对具体类目和图片位置；服饰等有特殊要求的类目不能直接照搬。案例数据见[总流程](/ecommerce/cross-border)。

## 先准备素材和规格记录

准备真实商品正面、开盖、细节照片，发货清单与外尺寸。记录“主图／副图、站点、类目、当前官方出处、核对日期、导出要求”。Amazon公开摄影指南提供白底、主体占幅和文件建议；它是公开指导，不替代当前类目后台规则。[官方摄影指南](https://sell.amazon.com/blog/product-photos)。

练习母版选2000×2000像素方图，属于本教程的制作建议。生成工具只支持其他像素时记录实际结果，再通过合成或裁切完成目标版式；放大不能补回不存在的真实细节。

## 第1步：做白底主图

1. 挑一张能看清完整盒体、盖子与发货内容的实拍；主体必须来自这一张真实素材。
2. 抠图后放入纯白画布，避免灰色渐变、纹理、装饰物与宣传标签。真实商品自身标识保留。
3. 主体放大到清晰可识别、四边不被裁切；用当前规则检查占幅，不能只看模型写了什么。
4. 对照原照片检查边缘、颜色、透明或反光区域。阴影不改变商品结构，不画出不存在的配件。
5. 使用[P10白底主图](/prompts/P10)；如果模型保不住主体，就只做背景／处理方案，再用真实商品层合成。

DN01的文具是场景道具，不出现在主图发货展示中。没有清晰照片时先补拍，不能从风格图借一个相似商品。

## 第2步：规划副图职责

| 图片 | DN01练习任务 | 要补的素材 |
| --- | --- | --- |
| 场景 | 放在书桌上说明用途 | 真实主体＋获准文具道具 |
| 结构 | 开盖与可拆隔板 | 开盖、隔板实拍 |
| 尺寸 | 长宽高与单位 | 外尺寸记录；不能画内尺寸 |
| 发货 | 盒体、盖子、隔板数量 | 包装／配件清单及照片 |
| 使用 | 打开、放文具、合盖 | 实际动作或可信步骤依据 |

用[P11](/prompts/P11)先生成逐张简报，不一次生成完整拼贴。照片未显示的背面或结构列待补；准确短文案独立排版。尺寸图使用[P18](/prompts/P18)，不要套用服装通用尺码表。

## 第3步：导出与实际页面检查

主图、副图单独命名并按顺序排列。核对实际像素、格式、体积、主体与文字；看缩略图是否一眼辨认。上传后查看桌面与手机实际商品页、裁切和变体对应，后台结果留记录。

本教程尚未进行Amazon后台上传。某个脚本给出PASS只能说明它检查了指定字段，不能代替商品真实性、类目要求和平台审核。
