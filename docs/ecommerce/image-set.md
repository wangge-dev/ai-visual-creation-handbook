# 从单图到一套商品图

以真实商品图和事实表为输入，先分配图片职责，再安排风格一致性。一套图片的数量按渠道和商品任务确定，下面的“1＋5”是练习结构。

| 图片 | 解决的问题 | 必须核对 |
| --- | --- | --- |
| 1 主图 | 买家一眼识别商品 | 主体真实、发货内容、渠道要求 |
| 2 场景 | 在哪里使用 | 大小关系、道具是否误导 |
| 3 细节 | 材质与关键结构 | 原图依据、没有补假结构 |
| 4 尺寸 | 是否合适 | 真实参数、单位、标注 |
| 5 使用 | 怎么操作 | 顺序和动作符合实际 |
| 6 信任信息 | 为什么可信 | 证明材料与准确文案 |

## 制作步骤

1. 按[商品简报](/ecommerce/product-brief)整理SKU与实拍。
2. 为每张图写一张任务卡，共用主体、色彩与字体，分别写构图和准确文字。
3. 使用[P01](/prompts/P01)先完成场景图，检查商品身份后再扩展。
4. 细节和尺寸图以真实照片与数据为底，准确文字用图层排版；需要改一处时使用[P06](/prompts/P06)。
5. 在[三类画布](/workflows/canvases)中分离候选、通过和返工版本。
6. 逐图检查，再检查整套一致性；导出文件名包含SKU、用途、语言与版本。

图像模型生成的细节放大不等于真实微观结构。证据图、检测报告和认证标识使用真实授权原件，不生成替代。
