## 二、你现在手上有什么资料，就按什么流程做

<!--heading:1-有清晰产品白底图-->

### 1. 有清晰产品白底图

这是最理想的情况。

流程：

```text
白底图 → 换背景 → 场景图 → 卖点图 → 详情页排版 → 质检
```

推荐工具：Pic Copilot、美图设计室、即梦、豆包、通义万相、Canva。

重点：保持产品主体不变，只改背景、光线和场景。

<!--heading:2-有手机随手拍产品图-->

### 2. 有手机随手拍产品图

流程：

```text
手机图 → 裁切矫正 → 抠图 → 清洁背景 → 调整亮度色彩 → AI生成场景图
```

注意：手机图如果模糊、反光严重、角度变形，AI后续也很难稳定。

<!--heading:3-有竞品参考图-->

### 3. 有竞品参考图

竞品图只能参考：

- 构图；
- 卖点表达；
- 颜色风格；
- 场景方向；
- 页面结构。

不能做：

```text
直接复制竞品图
照搬竞品文案
复刻对方模特/场景/品牌元素
把竞品图当成自己的产品图上传生成
```

正确流程：

```text
竞品图 → 提炼风格和结构 → 用自己产品图重新生成 → 后期排版自己的卖点
```

<!--heading:4-只有产品卖点没有图片-->

### 4. 只有产品卖点，没有图片

可以先做视觉方案，但不能直接当正式上架图。

流程：

```text
产品卖点 → 详情页结构 → 画面脚本 → 等真实产品图到位 → 再生成正式图片
```

适合提前准备：

- 详情页结构；
- 主图卖点；
- 场景方向；
- 拍摄清单；
- 提示词模板。

<!--heading:5-有一批sku-->

### 5. 有一批SKU

不要每个SKU重新想。先做模板。

流程：

```text
选3个代表SKU → 跑通风格 → 固定提示词 → 批量替换产品图 → 统一质检
```

重点：统一背景、光线、构图、命名规则。

<!--heading:6-做amazon-->

### 6. 做Amazon

```text
主图：真实白底图优先，AI只做轻修。
副图/A+图：AI可以做场景和品牌氛围。
```

<!--heading:7-做shopee-->

### 7. 做Shopee

```text
主图可更促销化，但产品必须清楚。
多语言文字后期添加，避免AI乱码。
```

<!--heading:8-做shopify独立站-->

### 8. 做Shopify独立站

```text
先定品牌视觉，再做产品图。
重点是统一色调、光线、构图和页面氛围。
```
