## 十三、标准电商AI作图SOP

<!--heading:1-输入资料-->

### 1. 输入资料

```text
产品名称
产品白底图/实拍图
颜色
材质
尺寸
核心卖点3-5条
目标平台
目标人群
价格带
竞品参考图
品牌风格关键词
禁止夸大的内容
```

<!--heading:2-输出素材-->

### 2. 输出素材

| 素材 | 用途 |
| --- | --- |
| 白底图 | 平台主图、SKU展示 |
| 主图 | 搜索和列表转化 |
| 场景图 | 展示使用环境 |
| 细节图 | 展示材质、结构、工艺 |
| 卖点图 | 解释核心功能 |
| 尺寸图 | 降低尺寸误解 |
| 对比图 | 表达差异，但不能虚假比较 |
| 详情页长图 | 国内平台详情页 |
| A+图 | Amazon品牌内容 |
| 独立站Banner | 首页、产品页、广告落地页 |
| Shopee促销图 | 活动和列表转化 |

<!--heading:3-标准流程-->

### 3. 标准流程

```text
资料准备
↓
确定平台策略
↓
选择工具
↓
生成提示词
↓
生成候选图
↓
筛选可用图
↓
后期排版文字
↓
多尺寸导出
↓
人工质检
↓
素材归档
```

<!--heading:4-图片命名规则-->

### 4. 图片命名规则

```text
SKU_平台_图片类型_序号_日期
例：HB001_Amazon_Aplus_03_202607
```
