## 十二、跨境平台方案：Amazon、Shopee、Shopify

2026-10-15补充：[新增TikTok Shop US实拍图组教程](https://wangge-dev.github.io/ai-visual-creation-handbook/#补充-tiktok-shop)。下文保留原稿叙述，规格以当前目标站点和模块为准。

<!--heading:1-amazon-->

### 1. Amazon

<!--heading:主图原则-->

#### 主图原则

Amazon主图要保守：

- 真实产品；
- 纯白背景；
- 产品完整清晰；
- 不加促销文字、徽章、夸张图标；
- 不放容易误导的道具；
- 长边建议至少1000px以上，方便缩放查看。

<!--heading:ai适合做什么-->

#### AI适合做什么

适合：

- 白底清洁；
- 去灰、去脏、轻微修瑕；
- 副图生活方式场景；
- A+品牌图；
- 功能模块配图。

不建议：

- 纯AI生成主图产品；
- 加入不存在的配件；
- 生成虚假认证、奖项、测试数据；
- 把材质做得比实物高级。

<!--heading:2-shopee-->

### 2. Shopee

Shopee更偏转化和促销，但产品仍要清楚真实。

适合AI做：

- 促销背景；
- 场景副图；
- 节日活动图；
- 多语言卖点图的背景；
- 商品详情图。

注意：

```text
多语言文字后期添加。
不要让促销元素盖住产品。
不要夸大发货物内容。
不同站点规则要单独核对。
```

<!--heading:3-shopify独立站-->

### 3. Shopify独立站

Shopify重点是品牌一致性。

适合AI做：

- 首页Banner；
- 产品页生活方式图；
- 品牌故事图；
- 类目页头图；
- 邮件营销图；
- 广告落地图。

视觉原则：

```text
统一色调 + 统一光线 + 统一构图 + 统一字体 + 统一场景风格
```

推荐流程：

```text
确定品牌关键词 → 生成品牌场景图 → Canva/PS排版 → 导出桌面端和移动端尺寸 → 压缩图片 → 上传站点
```
