## 十一、国内电商平台AI图合规边界

覆盖：淘宝、天猫、京东、拼多多、抖音电商、小红书电商。

<!--heading:1-会不会因为ai图被处罚-->

### 1. 会不会因为AI图被处罚？

更准确的说法是：平台关注的通常不是“是不是AI生成”，而是：

```text
是否虚假宣传
是否商品不一致
是否误导消费者
是否侵权
是否低质/违规营销
是否使用未授权品牌元素或认证标识
```

所以不要把AI图理解成天然违规，也不要把AI当成免责工具。

<!--heading:2-风险最高的ai图-->

### 2. 风险最高的AI图

| 风险 | 例子 |
| --- | --- |
| 产品被改形 | 杯子多了按钮，耳机多了接口 |
| 颜色被美化 | 实物灰白，AI做成珠光白 |
| 材质被升级 | 塑料变玻璃，PU变真皮 |
| 功效夸大 | 普通清洁用品做成“瞬间除菌99.99%” |
| 虚假认证 | 生成未授权检测标、奖章、平台标识 |
| 包装文字乱码 | 品牌名、规格、成分被AI改错 |
| 尺寸误导 | 小件商品被放得像大件 |
| 侵权风险 | 生成相似明星、品牌、IP元素 |

<!--heading:3-主图安全做法-->

### 3. 主图安全做法

```text
产品主体真实。
背景简洁。
促销文字后期添加。
不要过度特效。
不要暗示不存在的配件。
```

<!--heading:4-详情页安全做法-->

### 4. 详情页安全做法

```text
AI做场景和视觉。
参数、材质、尺寸、检测数据必须人工填写。
对比图不能捏造竞品数据。
效果图避免绝对化表达。
```

<!--heading:5-人工审核清单-->

### 5. 人工审核清单

```text
[ ] 产品主体是否与实物一致
[ ] 颜色是否准确
[ ] 材质是否真实
[ ] logo和包装文字是否正确
[ ] 是否出现未授权品牌/IP
[ ] 是否出现虚假认证或奖项
[ ] 功能表现是否有依据
[ ] 尺寸比例是否误导
[ ] 中文文字是否后期排版且清晰
[ ] 是否符合目标平台图片规范
```
