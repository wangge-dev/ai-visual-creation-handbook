# 从图像到短片分镜

先决定任务是分析已有视频还是创造新短片。已有素材中的动作需要看见或有明确证据；新镜头可以创作，但标为计划。

使用[P07](/prompts/P07)列时长、镜头、动作、运动、字幕和素材来源。先做关键帧检查商品或角色，再尝试运动；镜头间的结构和身份不应因为运动丢失。

制作状态分“脚本、分镜、关键帧、生成片段、剪辑、连续看听、最终导出”。画出关键帧不等于视频已生成。最终检查真实时长、节奏、字幕、声音与可播放文件；本项目首批尚无新生成视频案例。
