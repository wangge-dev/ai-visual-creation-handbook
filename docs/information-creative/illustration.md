# 插画、漫画与创意项目

先确定主题、读者、风格方向、故事顺序和固定角色。参考风格可描述构图、线条、色彩和材质，不把复制别人的整张作品作为目标。

漫画先写逐格动作与对话，再做一格或一个角色作为方向样稿。字框和较长对白独立排版，逐字核对；系列复用角色设定，见[P05](/prompts/P05)。

交付包含完整脚本、角色表、逐格结果和文字版本。未生成的格子标待补；不要把分镜方案当作漫画成品。后续待补连续动作、人物一致性与印刷适配案例。
