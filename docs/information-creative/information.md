# 信息图、教学演示与UI

输入准确文字、表格或系统关系。先抽出节点、方向、数量和必要图例，再选流程图、对照表或数据图。装饰不能改变逻辑，箭头不能凭空补因果。

使用[P04](/prompts/P04)列原始内容与禁止添加项。流程关系优先用可编辑的Mermaid或SVG；讲解草图可用Excalidraw。数值图由真实数据计算和绘图，检查单位、坐标和来源。

UI练习先列用户任务、状态和交互，再制作页面。界面效果稿与可操作软件分别交付；没有实现按钮、数据或权限的示意图明确标注。下载源文件需实际创建并打开检查。
