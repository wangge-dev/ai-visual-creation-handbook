# 封面、知识卡与出版配图

先从已确认正文提取标题、核心信息和图中必须出现的文字。封面承担识别主题，知识卡承担解释一个知识点，两者分开规划。

使用[P03](/prompts/P03)先做一张卡。没有来源的百分比、研究结论和人物引言不能为了“更专业”补入。图中文字少而准确，较长内容转成独立排版；系列复用字体、留白和色彩，不重复内容。

出版配图额外保留来源、授权和读者上下文。导出检查缩略图识别、手机文字可读性和实际平台裁切。公众号正文导出与网站界面分开，按钮、搜索框和维护信息不复制到正文中。
