# 公众号封面与正文图：从主旨到同文四图

### 先做一篇文章的四张图

练习文章主旨：“商品图出错，先检查输入，再改提示词。”目标读者是第一次用AI做商品图的运营。成套交付为封面＋输入清单图＋流程图＋返工对照图。本文已给出文案和排版示意，尚未生成成品图或测试公众号后台裁切。

### 1. 从文章提取视觉任务

```text
请根据我粘贴的文章正文规划配图，先不要生图。
主旨：商品图出错，先检查输入，再改提示词。
读者：第一次用AI做商品图的运营。
输出4张图：封面只表达主旨；正文图1解释需要什么输入；图2解释制作顺序；图3解释如何定向返工。
每张写明插入的段落、读者要理解的问题、画面内容、准确文字、与其他图共享的视觉规则。
只能使用文章已说明的事实。没有真实前后图时，把图3标为“返工方法示意”，不能生成假案例或伪造界面。
封面准确标题仅为“先备素材，再做商品图”。不要加入销量、效率百分比或工具官方Logo。
文章全文：[在此粘贴实际正文]
```

| 图 | 准确文字 | 读者判断 |
| --- | --- | --- |
| 封面 | 先备素材，再做商品图 | 缩成小卡片仍能看出“素材→商品图”，不靠读副标题理解 |
| 输入清单 | 正面／侧面／细节／参数 | 四类文件分清；参数用文本卡，不画成未知品牌后台截图 |
| 流程 | 整理事实→先做一张→核对主体→扩展套图 | 顺序有箭头，每步只有一个动作 |
| 返工方法示意 | 问题：文字压住主体；修改：只移动文字 | 用排版框示意文字位置变化；不把示意当真实AI返工图 |

### 2. 先锁一套视觉规则，再生成无字底图

本套使用暖白背景、深灰正文、橙色重点；线条和圆角保持一致。只在封面用一处主体，正文图减少装饰。先在公众号编辑器查看当前封面裁切框，再据此建画布；下方工作比例只是练习选择，不是公众号现行规格声明。

```text
为文章“商品图出错，先检查输入，再改提示词”制作无字封面底图。
画面左侧是一组整齐的照片卡片和一张资料卡，右侧是一张干净的商品展示卡，中间以一条简洁橙色箭头连接。商品用没有品牌和具体参数的抽象盒形物体，明确为流程插画。
暖白背景，深灰轮廓，橙色仅用作箭头与少量强调；平面信息插画，留白充分。
主体组合集中在画面中央，外围留足裁切余地，上部留标题区域。不要文字、字母、数字、Logo、水印、真实软件界面或装饰小标签。
只输出底图；文字由我后期用独立文字层添加。
```

### 3. 准确文字用图层排，正文信息图用形状排

用Photopea打开底图，新建文字层输入“先备素材，再做商品图”。需要两行时断为“先备素材”与“再做商品图”，不要断开“商品图”。正文图用矩形、箭头和文字层制作，避免让模型画四段小字。保留标题、标签、箭头、底图为不同图层，见[Photopea文字说明](https://www.photopea.com/learn/text)。

下面是可照着排的线框示意，不是AI成品。图3左侧故意示意压字问题，右侧示意将文字移出主体区。

| 封面／清单 | 流程图 | 返工方法示意 |
| --- | --- | --- |
| 上：两行标题<br>中：素材卡 → 商品卡<br>下：留白 | 整理事实<br>↓<br>先做一张<br>↓<br>核对主体<br>↓<br>扩展套图 | 修改前：标题叠在主体上<br>↓ 只移动文字层<br>修改后：标题在上，主体在下 |

### 4. 缩略图与同文多图如何检查

将封面复制到一张检查画布，分别缩成约300 px和150 px宽度，这是本教程自定的识别测试。看一眼能否读出主题；如果只有满屏装饰，删副标题、减少卡片数量、放大标题。接着在公众号草稿里实际裁切并预览：保住主物体与主标题，检查列表卡片和正文两种场景。后台未测前不能写“公众号适配已通过”。

```text
返工任务：保留已确认底图，只修改标题布局。
准确标题：先备素材，再做商品图。
问题：缩到150 px宽度时标题过小，右侧“商品图”接近裁切边缘。
修改：标题分两行，去掉副标题；标题和核心图形向中央收拢；增加四周安全留白。
保留暖白、深灰、橙色和原有图形风格。不得新增文案、字母或Logo。
如果是图层编辑，直接改文字层；如果是生成模型，仅修改无字背景构图，文字仍由我排版。
```

交付文件命名为cover-v01、body-01-input、body-02-flow、body-03-rework；一并保存可编辑源文件与准确文案。四图并排检查字体、橙色、线条粗细、背景和留白，逐张100%核字。来源阅读：[R217](#wechat-R217)；本节指令为围绕本篇主旨重新编写。
