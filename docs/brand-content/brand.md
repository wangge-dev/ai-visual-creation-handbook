# 品牌KV、包装与广告入口

输入品牌简报、已授权Logo、准确文案、产品实拍、用途和尺寸。先明确视觉方向，再做一张主视觉；批准后扩展横幅、海报和不同尺寸广告。

用[P02品牌KV](/prompts/P02)准备完整任务。商品、Logo、准确文字与背景分层处理，文字留可编辑排版。包装设计额外需要真实刀模、出血、材质和印刷要求；效果图只表现外观，不冒充可以直接印刷的生产文件。

交付时分别列“效果预览、准确文案、可编辑源文件、生产文件”状态。没有实际创建的矢量或PSD文件不写成已交付。后续待补：真实刀模案例、印刷检查和多尺寸广告对照。
