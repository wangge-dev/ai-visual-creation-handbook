# 按任务开始：从素材到交付

先选手里的素材，再选要交付的内容，最后核对平台。1张、6张与10屏是练习结构，不是平台固定数量。

### ① 有清楚的商品照片吗？

没有 → [前置准备与拍摄](#一小白先看电商ai作图从哪里开始)；有 → [整理商品事实与素材](../ecommerce/product-brief.md)。

### ② 这次交付什么？

[一张可用图](first-image.md) → [一套商品图](../ecommerce/image-set.md) → [逐屏详情页](../ecommerce/detail-page.md)

内容创作：[公众号封面与正文图](../brand-content/wechat-visuals.md)；处理已有照片：[局部修图与创作](../workflows/local-retouch.md)。

### ③ 要投放到哪里？

[Amazon Listing](../ecommerce/amazon-listing.md) → [A+模块](../ecommerce/amazon-a-plus.md)；[Shopify产品媒体](../ecommerce/shopify-product.md)；[Shopee站点与变体](../ecommerce/shopee-localization.md)。

### ④ 检查后再交付

[语言与单位](../ecommerce/localization.md) → [SKU与导出](../ecommerce/sku.md)。出现问题回到对应步骤返工，不必整套重做。

想换制作工具：[设计画布／节点／图层衔接](../workflows/canvases.md)；想找延伸材料：[公众号文章按任务筛选](../resources/wechat-reading.md)。
