# 第一张可用图：先完成一个任务

准备一张清晰素材、一个明确用途、目标比例和准确文案。首次练习可以用自己拍摄的物体或虚构品牌；商品照片承担外观依据，参考图承担风格或布局依据。

## 操作顺序

1. 写一句交付目标，例如“为真实收纳盒做一张书桌场景图，无文字，3:4”。
2. 标明每张输入图的角色；列必须保留的外观与允许变化的背景。
3. 选择工具时确认实际支持参考图、局部编辑、尺寸和导出格式；在当前入口核对，不根据模型名字推断。
4. 使用[P01商品场景模板](/prompts/P01)先做一张。主体容易漂移时，改为生成背景后合成真实主体。
5. 对照原素材检查形状、颜色、部件、配件、文字和边缘。一次只改一个关键问题。
6. 保存原素材、实际提示词、结果和修改说明，检查实际像素与文件格式。

## 怎样判断完成

“图看起来不错”还不足以交付。商品身份、内容准确、可读文字、目标裁切和可打开文件都满足任务，才算这一张可用。没有运行结果时，只能报告方案或模板完成。
