# 参考图与文件角色

多图输入之前，先做素材清单。图1是真实对象，图2只参考布局，图3只参考色彩，这样比“照着做”更容易定位错误。

| 输入 | 可借用的内容 | 需要保护的内容 |
| --- | --- | --- |
| 商品实拍 | 可见外观与包装 | 形状、部件、颜色、准确标识 |
| 竞品或风格图 | 场景、光线、留白关系 | 不挪用其商品、Logo、参数 |
| 人物参考 | 已获授权的可见特征 | 不凭空补未提供身份与经历 |
| 文案与表格 | 已确认文字与数值 | 不生成额外功效、比例或因果 |

修改时另列“可改区域”和“保护区域”。提示词中的“其余不变”不能证明像素真的未变；需要精确保留时使用蒙版与图层，把原主体留在独立层，再检查修改边界。

如果照片看不清背面、接口或小字，先补素材。推测的结构可以作为概念草图，不能作为商品实物图。局部编辑见[P06](/prompts/P06)。
