# 摄影、场景与空间表现

先分清照片精修、真实物体合成和概念空间设计。真实空间照片涉及结构、家具尺度和现有物体；概念设计可以提案，但不能冒充已落地实景。

输入原照片、尺寸或平面资料、允许改变区域、材质与光线参考。修改清单明确保留墙体、门窗或主体，先调整一处，再核对透视、光向、接触阴影和边缘。保留主体的合成方法与电商场景相通，见[P01](/prompts/P01)和[P06](/prompts/P06)。

验收需要对照原始资料，尤其检查空间关系和无法核实的新增结构。效果图不能代替施工图、尺寸图或现场核验。
