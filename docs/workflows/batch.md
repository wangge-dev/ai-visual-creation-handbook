# 批量任务与返工记录

先让一项输入、生成、检查和导出能完整通过，再复制成批量任务。批量清单最少包含任务ID、SKU、素材、语言、用途、完整提示词、状态、结果和返工原因。

输入准备、生成和校对分开记录。成功、有结果待检查、失败和未知不是同一种状态。发生中断先查原任务与结果，不能把没有收到回执当成从未执行。

外部Skill可以帮助组织简报或清单，但它是否有生成适配器、实际脚本和示例结果需要读代码与产物。README承诺、流程图和本项目运行分别注明。

用[P08](/prompts/P08)规划画布与交付。保持原任务ID；每次扩批先检查相关输入角色和失败类型，不对所有无关任务重复测试。
