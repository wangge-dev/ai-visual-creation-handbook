# 局部修图与照片创作：修改边界与前后核对

### 选择一种目标：修复照片，或创作新画面

修复要求忠于已有照片，例如去除桌面污点；创作允许改变环境，例如把旅行照片做成水彩明信片。二者分别保存，不能把创作出的建筑细节说成原现场。本节使用你自己有权处理的照片；没有附真实前后样图，下方失败情况均为教学判断示例。

### 1. 先写修改区、保留项与不确定项

| 项目 | 局部修图练习 | 照片创作练习 |
| --- | --- | --- |
| 原始输入 | 商品桌面照，主体左侧有一处污点 | 本人旅行照片，背景有建筑 |
| 修改区 | 只选污点及其紧邻背景，避开商品轮廓和阴影 | 允许全画面水彩化；人物身份与姿态保持 |
| 保留项 | 商品像素、Logo、文字、颜色、位置、接触阴影 | 人物数量、脸部识别特征、主要建筑位置 |
| 不确定项 | 污点下原本纹理不可完全恢复，只能合理补全 | 被遮挡细节不可考证，不声称纪实复原 |
| 输出 | 修复版＋原图＋局部放大对照 | 创作版＋原图；说明这是风格化创作 |

```text
任务：只去除参考照片中我选中的桌面污点。
输入A是原始照片，输入B是区域示意。B的标记只说明位置，不得出现在成品中。若工具支持蒙版，使用实际蒙版；若不支持，先说明无法严格限制区域。
修改区：商品左侧的桌面污点及紧邻背景，不跨过商品边缘。
保留：商品形状、Logo、文字、材质、颜色、位置、大小、光照和接触阴影；所有未选区域。
用相邻桌面连续的颜色、透视和纹理补齐该区域，不添加道具，不磨皮整个画面，不锐化商品，不改变背景风格。
输出新文件repair-v01，保留原图。若改动必须触及商品，停止并指出冲突，不替我重画商品。
```

### 2. 实际操作顺序：复制图层、选区、生成、蒙版合回

打开原图并保存工作副本，锁定底层。用套索圈出污点，边界落在干净背景上；不要让选区压到Logo或商品轮廓。将局部编辑结果作为新图层放在原图上方，对齐后添加蒙版，只显露需要修复的区域。模型即使改了其他位置，合回时也不采用那些像素。蒙版白色显示、黑色隐藏的基本方式见[Photopea蒙版说明](https://www.photopea.com/learn/masks)。

如果工具不支持蒙版输入，把“局部生成”视为候选素材，仍在图层软件中合回。若局部纹理无法接上，先缩小处理范围、分两次修补；不要反复对整张图生成。保存可编辑文件和导出图各一份。

### 3. 前后对照不是两张缩略图看着像

| 检查动作 | 通过条件 | 失败后做什么 |
| --- | --- | --- |
| 原图与结果同尺寸叠放，切换上层可见性 | 未编辑主体不跳动、不缩放、不改变颜色 | 重新对齐；主体被重画则退回原图合成 |
| 100%查看污点周围及商品边缘 | 纹理连续、没有重复贴片或明显糊斑 | 缩小选区重新修补，保留已通过区域 |
| 200%查看Logo、刻字、细线 | 与原图相同，不能靠锐化猜文字 | 从原图恢复这一区域，不让模型补字 |
| 缩到实际使用宽度检查整体 | 修补区亮度一致，不抢主体 | 只调修补图层亮度与蒙版过渡 |

```text
仅返工上次修补区。
观察：修补区比右侧桌面更亮，接缝可见；商品和文字目前正确。
修改：匹配紧邻桌面的亮度与纹理方向，消除接缝。
保留：所有商品像素、接触阴影、画面构图与未选背景。不要增强全图，不添加纹理装饰。
输出repair-v02供局部合回，不能覆盖原图与repair-v01。
```

### 4. 把同一张照片做成创作图

```text
以我上传的旅行照片为构图和人物参考，制作一张水彩明信片插画。
保留人物数量、人物姿态、可辨识的面部特征、服装主色、主要建筑相对位置。
允许改变：纸张质感、笔触、简化背景小细节、柔化光线。不能增加同行者、名胜、路牌文字或改变人物年龄。
边缘留出后期排字区域，不生成日期、地名、印章或任何文字。
这是艺术创作，不是历史或现场复原。输出creative-v01，与原始照片分开保存。
```

若脸部身份变化，先用原照片裁切人物并在图层中保留，背景单独风格化；人物仍不匹配就停用这张结果。若想增加不存在的场景，明确标为想象创作。不要以“高清修复”名义交付模型编出的细节。

### 5. 交付一张能复查的对照板

对照板按“原图｜首版｜返工版”三列排列，使用相同裁切与比例；下方各放一块同位置的局部放大。写清实际修改区、保留项、出现的问题及本轮修正，不能用不同曝光或缩放掩盖差异。若未执行，文件记录只写待执行，不填假结果。

```text
原始文件：
用途：修复／创作
修改区域与蒙版文件：
保留项：
首版文件／实际观察：
返工指令／返工文件：
100%纹理检查：通过／返工／未执行
主体和文字与原图对照：通过／返工／未执行
交付文件：原图、蒙版、可编辑源文件、最终图、对照板
仍存在的限制：
```
