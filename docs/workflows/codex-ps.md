# 用Codex协作PS作图修图

先明确Codex当前实际能操作什么：本地文件、脚本入口、已配置连接或可用UI控制。具体可用方式取决于本机环境，不能因为能写脚本就宣称已经控制PS。

## 一个可执行任务怎么组织

输入真实商品照片、背景素材、准确文字、目标尺寸和保护区域。让Codex先整理图层计划与操作步骤；检测实际PS版本及可用脚本／插件入口后，再用一张练习图运行。

1. 在副本中打开素材，建立真实主体、背景、阴影、文案图层。
2. 抠图与局部修复采用蒙版；不要覆盖原素材。
3. 用已确认文字排版，核对字号、换行和Logo。
4. 保存工作副本与PSD，重新打开检查图层、蒙版与可编辑文字。
5. 导出预览文件，报告实际像素、格式与绝对保存位置。

可以要求：“仅修改背景和接触阴影，保持原商品层；遇到不支持操作时说明阻塞，不把操作方案当作执行成功。”完整局部修改任务见[P06](/prompts/P06)。
