请写一章“API、API Key、账号订阅、会员额度到底是什么”。

目标读者是小白，必须讲清楚：
1. 开了ChatGPT会员或某个AI网站会员，不等于可以免费用API。
2. 网页端订阅和API通常是两套计费。
3. API Key是给程序调用的钥匙，不要随便发给别人。
4. API适合批量处理，不适合小白一开始就上。
5. 免费额度适合测试，不适合稳定生产。
6. 中转站有成本优势，也有稳定性、合规、数据安全和封号风险。

请用表格对比：
- 免费版
- 账号订阅/会员
- 积分包
- API官方接口
- 第三方聚合/API中转

请给出小白决策建议。
